# Add an Evidence-Driven Learning Log

## Intent

Give projects a portable way to retain evidence from agent failures and convert recurring prevention into enforceable instructions.

## Specification

- Add an optional `[BP-WF-LEARN]` workflow to the blueprint.
- Define bounded logging, root-cause verification, rule promotion, and post-promotion handling.
- Add an optional trigger bridge to the canonical and compatibility `AGENTS.md` templates.
- Attribute the originating practitioner report in `references/sources.md`.

## Acceptance Criteria

- [x] The workflow distinguishes actionable mistakes from expected exploration and external failures.
- [x] The entry schema separates verified root causes from unknown causes.
- [x] Repeated evidence promotes prevention into the narrowest canonical instruction without duplicating policy.
- [x] The Reddit source is recorded in the durable bibliography.
